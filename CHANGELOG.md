## [1.0.0] - 2025-01-11

### Added
- Initial release of Word to PDF Converter
- React frontend with Vite and Tailwind CSS
- Node.js backend with Express
- File upload functionality for .docx files
- PDF conversion using docx-pdf library
- Modern responsive UI design
- Real-time conversion status feedback
- Automatic PDF download after conversion
- CORS configuration for secure cross-origin requests
- Environment variable support
- Comprehensive documentation
- Development setup scripts for Linux/macOS and Windows
- Deployment guides for multiple platforms
- Contributing guidelines
- MIT License

### Features
- ✅ Upload .docx files via drag & drop or file picker
- ✅ One-click PDF conversion
- ✅ Automatic file download
- ✅ Real-time loading states
- ✅ Error handling and user feedback
- ✅ Responsive design for all devices
- ✅ Fast performance with Vite
- ✅ Modern UI with Tailwind CSS

### Technical Details
- **Frontend**: React 19.1.0, Vite 7.0.4, Tailwind CSS 3.4.17
- **Backend**: Node.js, Express 5.1.0, Multer 2.0.2
- **Conversion**: docx-pdf library
- **Icons**: React Icons 5.5.0
- **HTTP Client**: Axios 1.11.0

### Developer Experience
- ESLint configuration for code quality
- Development scripts for easy setup
- Hot reload in development
- Build optimization for production
- Environment variable support
- Comprehensive error handling
